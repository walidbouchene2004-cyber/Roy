# Roy Parametric EQ (VST3)

معادل باراميتريك: Low Cut + 5 نطاقات (Low Shelf / 3 Peaking / High Shelf) + High Cut + Master Gain.

## الواجهة
- اسحب النقاط على المنحنى: أفقياً = Frequency، عمودياً = Gain
- عجلة الماوس فوق نقطة = Q
- دبل كليك على نقطة = تشغيل/إيقاف النطاق

## البناء (بدون تثبيت أي شيء)
1. أنشئ مستودعاً جديداً على GitHub وارفع محتوى هذا المجلد
2. تبويب Actions ← Build VST3 ← انتظر حتى ينتهي
3. حمّل Roy-Parametric-EQ-VST3 من قسم Artifacts وفك الضغط
4. انسخ المجلد `Roy Parametric EQ.vst3` إلى: `C:\Program Files\Common Files\VST3`
5. في أوديشن: Effects ← Audio Plug-in Manager ← Scan for Plug-ins
